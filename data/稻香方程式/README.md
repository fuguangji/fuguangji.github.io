# 稻香方程式章節格式

## 獨立章節檔

- 檔名使用阿拉伯數字加 `.md`，例如 `1.md`、`2.md`，依章節編號排列；目前有 `1.md` 至 `63.md`。
- 每個單章檔名與首行章號一致；原稿重複的第二十四、二十五章已依序順延編號。
- 每個檔案的首行格式為「第 N 章 標題」，例如：`第一章 啟程`。
- 首行之後直接接章節正文，不另加書名或 Markdown 標題符號。

## 彙整檔

- `all.md` 是合併多章內容的彙整稿，不按單章檔名規則命名；拆分後仍保留此彙整檔。
- 彙整稿的章首格式為「稻香方程式 第 N 章 標題」，例如：`稻香方程式 第九章 再一次戰鬥`。
- 獨立章節檔移除章首的書名，只保留「第 N 章 標題」。
